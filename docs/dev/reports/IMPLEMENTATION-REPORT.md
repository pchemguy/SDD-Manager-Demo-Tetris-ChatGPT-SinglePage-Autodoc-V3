## Resolved findings and limits

QC repaired an omitted Enter help mapping, unreliable Playwright virtual-clock play scenarios, a real pre-key elapsed-time ordering bug, and a settings outcome alias. Actual browser play now uses native animation time and observable state; deterministic engine/controller timing tests still verify exact boundaries. SQL fixture ID collisions, returned-function auto-invocation in an asynchronous browser fixture and assertions comparing renewed cookie expiry times were corrected as test defects before acceptance. Their owning reports preserve evidence and distinguish them from application defects.

This managed host requires the documented process-local Firefox sandbox override for trusted application tests. Its browsers do not trust the network proxy's certificate; local SQLite checks use TLS-fetched, hash-verified bytes routed only for the exact pinned URL, with browser SRI still enforced. Hosted checks verify direct CDN loading without either local fallback. No TLS verification was disabled and no host trust was modified.

Native Windows and headed OS-window event delivery were not verified. Focus/visibility handlers and Restore chooser cancellation include modeled DOM events; Save dialog Escape cancellation is exercised through actual keyboard input. Live HTTPS hosting was not tested; Secure cookie behavior is checked at the HTTPS adapter boundary. These limits do not remove required file/HTTP/browser coverage. SQLite needs CDN access on first use; core gameplay and JSON work independently. The application deliberately accepts the documented canonical SQLite format rather than arbitrary equivalent database designs.
